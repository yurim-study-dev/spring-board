## 1.1 요구사항 기능 명세 표

| 요구사항 ID | 구분 | 기능명 | 담당자 | 우선순위 | 상세 내용 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| REQ-USER-01 | 회원 | 회원가입 | 용쌤 | 1순위 | 이메일, 비밀번호, 이름, 전화번호 입력 받아 member DB 테이블에 저장 |
| REQ-USER-02 | 회원 | 로그인/로그아웃 | 용쌤 | 1순위 | 이메일/비밀번호 DB 검증 후 HttpSession 생성 및 파기 |
| REQ-USER-03 | 회원 | 소셜 로그인 | 용쌤 | 3순위 | 카카오/네이버 OAuth 연동을 통한 외부 회원 로그인 처리 |
| REQ-POST-01 | 게시글 | 질문 목록 조회 | 하루 | 1순위 | 전체 질문 게시글 목록 표시 및 상세 이동 (post 테이블 조회) |
| REQ-POST-02 | 게시글 | 질문 게시글 작성 | 하루 | 1순위 | 로그인 세션 유효 시 기술 질문 제목과 본문 입력받아 등록 |
| REQ-POST-03 | 게시글 | 질문 상세 조회 | 하루 | 1순위 | 질문 상세 내용 및 등록된 답변 댓글(reply) 목록 함께 표시, 조회수 증가 |
| REQ-POST-04 | 게시글 | 페이징 및 키워드 검색 | 하루 | 2순위 | 게시글 목록 페이지당 10개 페이징 처리 및 질문 제목/내용 검색 기능 |
| REQ-POST-05 | 게시글 | 익명 에러 질문 작성/삭제 | 하루 | 3순위 | 비로그인 상태에서 비밀번호 입력 후 질문 등록, 삭제 시 비밀번호 확인 검증 |
| REQ-REPLY-01 | 댓글 | 답변 댓글 작성 | 나무 | 2순위 | 질문 상세 페이지 하단 폼에서 답변 내용 입력 및 reply 테이블 저장 |
| REQ-REPLY-02 | 댓글 | 답변 댓글 삭제 | 나무 | 2순위 | 본인 작성 답변 댓글 세션 확인 후 삭제 처리 |
| REQ-REPLY-03 | 댓글 | 답변 댓글 수정 | 나무 | 3순위 | 본인 작성 답변 댓글 세션 확인 후 내용 수정 폼 제공 및 반영 |
