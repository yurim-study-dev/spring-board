## 1.1 기획 개요

### 1.1.1 프로젝트 배경 및 목적
백엔드 부트캠프 수강생 간 자바 및 스프링 기술 질문, 에러 트러블슈팅 경험, 학습 노하우를 자유롭게 공유할 수 있는 개발자 전용 지식 Q&A 커뮤니티 서비스(사자샘터) 구축.

### 1.1.2 서비스 주요 특징
- 회원가입 및 HttpSession 기반 로그인/로그아웃 세션 인증 처리
- 기술 질문 게시글 작성, 상세 조회, 수정, 삭제(CRUD) 지원
- 비회원도 빠르게 에러 상담을 남길 수 있는 비밀번호 검증 기반 익명 게시글 옵션 제공
- 답변 댓글 작성, 삭제, 수정 기능 및 서버 사이드 렌더링(Thymeleaf) 동적 뷰 제공

---

## 1.2 주요 기능 요구사항

### 1.2.1 회원 관리 기능
- 회원가입 (이메일, 비밀번호, 이름, 전화번호)
- 로그인 및 로그아웃 (HttpSession 세션 생성 및 파기)
- 마이페이지 회원 정보 조회 및 수정

### 1.2.2 게시글 관리 기능
- 기술 질문 게시글 목록 조회 (페이징 및 키워드 검색 포함)
- 기술 질문 게시글 상세 보기 (조회수 증가 처리)
- 게시글 작성, 수정, 삭제 (본인 작성 글 제어)
- 비회원 익명 질문 작성 및 비밀번호 검증 삭제

### 1.2.3 답변 댓글 관리 기능
- 기술 질문 상세 화면 내 답변 댓글 작성
- 답변 댓글 목록 조회 및 본인 댓글 삭제/수정

## 1.3 팀 구성 및 도메인별 역할 분담

### 1.3.1 팀명 및 역할 분담표 (팀명: 사자들)

| 이름 | 직책 | 담당 도메인 | 세부 구현 내용 |
| :--- | :--- | :--- | :--- |
| 용쌤 | 팀장 | 회원 관리 | 회원가입, 로그인/로그아웃, 마이페이지, HandlerInterceptor 세션 검증 |
| 하루 | 발표 | 게시글 관리 | 게시글 목록/상세/작성/수정/삭제, 페이징 및 검색, 익명 게시글 관리 |
| 나무 | 서기 | 댓글 관리 | 답변 댓글 작성, 삭제, 댓글 수정 |

### 1.3.2 역할 분담 원칙
모든 팀원이 특정 기술 레이어에 치우치지 않고, 각자 맡은 도메인에 대해 화면(UI)부터 DB 처리까지 수직 슬라이스 형태로 구현.

### 1.3.3 팀원별 도메인 담당 정의
#### 1) 용쌤 (팀장)
- 총괄 역할: 프로젝트 초기 환경 구성, Git/GitHub Projects 체계 수립, 세션 검증 인터셉터 설정
- 담당 도메인: 회원 관리 기능 (회원가입, 로그인/로그아웃, 마이페이지)

#### 2) 하루 (팀원)
- 담당 도메인: 게시글 관리 기능 (질문 게시글 목록, 상세 조회, 작성, 수정, 삭제, 페이징 및 검색, 익명 질문 관리)

#### 3) 나무 (팀원)
- 담당 도메인: 댓글 관리 기능 (답변 댓글 작성, 삭제 및 수정)
